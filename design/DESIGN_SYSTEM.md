# AletheIA — Sistema de Diseño

## 1. Identidad visual

AletheIA utiliza una identidad visual minimalista, tecnológica y profesional.

La interfaz busca transmitir confianza, precisión y transparencia, utilizando una estética oscura con acentos azules y elementos visuales simples.

El diseño debe mantenerse consistente en todas las interfaces del producto.

---

## 2. Paleta de colores

### Colores principales

- **Navy:** `#0B1B2B`
  - Fondos principales y secundarios.

- **Blue:** `#1A6DB5`
  - Botones principales, acciones y elementos destacados.

- **Blue Light**
  - Estados activos, acentos y elementos interactivos destacados.

- **Ice / White**
  - Títulos y textos principales sobre fondos oscuros.

- **Muted**
  - Textos secundarios, descripciones y elementos de menor jerarquía.

### Uso de colores

El azul debe utilizarse principalmente para destacar acciones importantes y elementos interactivos.

Los fondos oscuros deben predominar para mantener la identidad visual de AletheIA.

---

## 3. Tipografía

La interfaz utiliza una tipografía moderna, limpia y legible.

### Jerarquía tipográfica

- **Títulos:** mayor tamaño y peso para destacar información principal.
- **Subtítulos:** tamaño intermedio y peso semibold.
- **Texto:** tamaño cómodo para lectura.
- **Botones:** peso semibold para facilitar su identificación.

La jerarquía debe mantenerse consistente en todas las pantallas.

---

## 4. Componentes

### Botones

Los botones principales utilizan:

- Color azul institucional.
- Texto claro.
- Bordes redondeados.
- Contraste suficiente.
- Estados visuales para interacción.

### Inputs

Los campos de entrada utilizan:

- Fondo oscuro.
- Bordes sutiles.
- Texto claro.
- Placeholder en tono secundario.
- Estado `focus` destacado mediante azul claro.

### Cards

Las tarjetas utilizan:

- Fondo ligeramente diferenciado del fondo principal.
- Bordes sutiles.
- Esquinas redondeadas.
- Espaciado interno adecuado.

### Tabs

Los tabs permiten cambiar entre diferentes modos de entrada, como:

- URL
- Texto

El elemento seleccionado debe diferenciarse visualmente mediante el color azul institucional.

---

## 5. Estados interactivos

Los componentes interactivos deben contemplar diferentes estados:

- **Normal:** estado predeterminado.
- **Hover:** indica que el elemento puede ser seleccionado.
- **Focus:** indica que el elemento está seleccionado o activo.
- **Active:** indica una acción actualmente seleccionada.
- **Disabled:** indica que una función no está disponible.

Los cambios de estado deben ser sutiles y mantener la identidad visual.

---

## 6. Espaciado y formas

Se utilizará un sistema de espaciado consistente para mantener orden y legibilidad.

Los componentes principales utilizarán bordes redondeados para reforzar una estética moderna y tecnológica.

Debe evitarse la saturación visual y conservar suficiente espacio entre los elementos.

---

## 7. Iconografía

Se utilizarán iconos simples y fácilmente reconocibles.

Los iconos deben complementar la información sin generar ruido visual.

Se priorizará un estilo de iconografía consistente en todo el producto.

---

## 8. Principios de diseño

El diseño de AletheIA debe seguir los siguientes principios:

- Minimalismo
- Profesionalismo
- Tecnología
- Legibilidad
- Claridad
- Consistencia
- Accesibilidad
- Espaciado adecuado

Se deben evitar elementos decorativos innecesarios que puedan distraer de la función principal del sistema.
